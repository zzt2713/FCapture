# 更新日志

本文件记录每个版本的用户可见改动。**新版本写在最上面。**

维护规则见 `CLAUDE.md` 的「更新日志（强制）」一节。

## v1.5.1（未发布）

### 新增

- **工具栏位置改为选区右下角**：截图后的标注工具栏不再水平居中，改为左端对齐选区右边缘、位于选区下方外侧
- **贴图重新标注**：贴图窗口悬停时左上角出现「编辑」「关闭」两个圆形按钮，点编辑可叠加标注层，确认后烘焙进图片，重复标注无需重新截图
- **白板快捷键**：首选项 → 控制新增「白板」一项，可绑定全局热键；托盘菜单同步显示当前绑定

### 优化

- **标注交互对齐 Snow Shot**：鼠标经过未选中的标注时显示主色虚线候选框；点击选中后锚点由灰色方块改为圆形（主色填充 + 白描边），旋转手柄改为方头以便区分；选中框改为主色实线、线宽 1px 并紧贴图形外沿
- **按工具区分鼠标样式**：文字工具为 I 形光标，套索为普通箭头，框选截图区域与其余绘画工具为十字
- **更新改为就绪确认**：下载并校验完成后不再自动弹出安装确认窗，关于页只显示「更新已就绪：x.y.z」，按钮从「下载更新」变为「重启并更新」
- **安装前二次确认**：用户主动点「重启并更新」后才弹确认框，默认按钮为「取消」，防止误触导致程序重启
- **下载失败可重试**：失败后按钮退回「下载更新」；重新点「检查更新」会重置就绪状态并作废已下载的包
- **尺寸标签平滑跟随**：拖拽调整选区时，尺寸标签不再是硬跳，而是缓动跟随选区左上角
- **标注工具按下动效**：工具栏按钮新增按下反馈，按下时底色加深、图标轻微收缩，90ms 内回弹
- **贴图缩放 HUD 跟随光标**：缩放百分比不再固定钉在图片左上角，改为平滑跟随光标位置，滚动滚轮时像"追着"鼠标走

### 修复

- **旋转后缩放导致图形乱飞**：旋转支点改为首次旋转时锁定，之后拖锚点缩放不再移动支点
- **贴图编辑态无法选中标注**：激活绘制工具时点击已有标注会先选中它，而不是在上面叠画新图形
- **选中标注后点选区空白处无法取消选中**：现在会先取消选中，而不是变成拖动整个选区

## v1.5.0（2026-11-12）

### 新增

- **多快捷键**：每个动作可绑定多个按键，配置弹窗支持添加 / 删除。录制时按下的键先预览，点绿色对勾才写入
- **识别框过渡动画**：首选项 → 截图 → 检测，三档可选（关闭 / 柔和约 100ms / 快速约 67ms）。关闭时高亮框瞬间切换
- **全屏游戏屏蔽**：开启后只识别真正的全屏游戏，全屏看视频不再屏蔽截图热键

### 优化

- **元素识别提速**：懒加载树已建立的窗口跳过 MSAA 探测；新增纯本地命中测试，悬停零跨进程调用；子节点超过 24 个时按行分桶索引；树可用时不再执行冗余的 UIA 兜底查询；光标下窗口句柄按坐标缓存 200ms
- **热键冲突按单键标红**：同一动作下只有真正被占用的键变红，其余键保持正常
- **托盘菜单实时跟随改键**：改完快捷键后菜单标签立即更新

### 修复

- 点击快捷键设置闪退（重建行时同步删除正在派发鼠标事件的控件）
- 快捷键 `F1` 显示成省略号（绘制区域比文字窄 1 像素触发省略）
- 首选项刚打开时不显示热键冲突红框，点开编辑一次才显示
- 截图原位贴图被挤到任务栏上方（钳制与吸附误用了工作区边界）
- 贴图窗口设置置顶状态时闪一下（状态未变仍重建原生窗口）

## v1.4.0

### 智能选区

- 修复元素间切换不流畅：过渡动画定时器创建后从未启动，高亮框一直是"瞬移"
- 窗口模式与元素模式真正分离：窗口模式锁定最外层窗口、滚轮不参与
- 窗口模式不再走 UIA，直接读缓存的窗口索引，省掉每次悬停 100~300ms 的跨进程往返
- 窗口矩形缓存改为按光标坐标精确命中，修复重叠窗口下复用旧结果
- 切换元素层级前按当前光标重新命中，并暂存待切层数，滚轮不再被吞
- 跳过整屏祖先层时保持用户实际滚到的层级，不再跳格
- `Tab` 提示行显示当前检测模式

### 取色面板

- 重做为 snow 风格单面板：11×11 像素网格、X/Y 坐标、整行色块（文字随明暗反色）
- 移除不再使用的 InfoPanel
- 鼠标停住时面板不再消失（置顶守卫会把它压到遮罩下）

### OCR

- 放大策略改为按估算文字高度归一化，不再按图片长边
- 输出文字集与语言不符时换互补语言重试
- 快速通道：首道结果可信时跳过其余候选
- 改用 Gray8 位图 + 灰度预处理，临时缓冲减半
- 结果窗口支持重识别回填、小图自动放大、滚轮缩放、空格拖拽平移
- 默认只高亮鼠标经过或选中的行

### 修复

- 弹出菜单期间隐藏取色面板与放大镜
- 鼠标进入工具栏时收起取色面板
- 修复 `OcrEngine` 悬空指针与卡死状态（连续识别几次后无响应）
- 打包补上缺失的 MSVC 运行时 DLL（MSVCP140 / VCRUNTIME140 系列）

## v1.3.0

### 元素识别（重写）

- UIA 查询改为按窗口的懒加载树：节点按需展开、跨请求常驻缓存，重复悬停零跨进程调用
- 改用 `CUIAutomation8`，`IUIAutomation2` 的超时设置真正生效
- 精化改为同步执行（原来排队后必被新请求作废，树从未真正建立）
- UIA 成为主路径，MSAA 只用于垫第一帧
- 排除全屏游戏 / 录制叠加层（NVIDIA GeForce Overlay 等），修复有窗口打开时任务栏和所有窗口都识别不到
- UIA 无子级时回退到直接子窗口 HWND（任务栏图标是自绘的）
- 按系统真实命中判断窗口，不再靠矩形猜测
- 修复展开时 `TreeNode` 悬空引用导致的崩溃

### 长截图

- 内联悬停预览取代独立预览窗口：悬停缩略图时，选区里直接显示对应区段
- 最近拼接的区段在缩略图中高亮

### 截图层

- 快捷键提示改为子控件，由 Qt 负责重绘，消除手算脏区导致的重影
- 选区或悬停框覆盖提示框时整块隐藏
- 放弃脏区局部重绘，改为整屏重绘

### OCR

- 结果窗口改为左图右文，支持图文联动高亮、行框选、文字高亮视图
- 识别从最多 4 次降为 1 次

### 修复

- 高 DPI 下截图被放大 1.5 倍
- 长截图悬停预览遮挡工具栏导致无法保存
- 保存对话框中按 `Esc` 会中止整个长截图会话
- 拖拽卡顿（不再每帧重建整屏 pixmap）
- 拖拽时尺寸标签与锚点残影

## v1.2.0

### 新增

- **二维码 / 条码识别**（基于 ZXing-C++，完全离线）：支持 QR、DataMatrix、Aztec 及各类一维码；一图多码，识别结果可复制，内容为网址时可直接打开浏览器；识别到的码会在选区上高亮标出
- **工具分组下拉**：工具栏从 14 个按钮收纳为 7 组（形状 / 线条 / 手绘 / 文字 / 像素 / 橡皮擦 / 序号·放大镜·套索），组内成员在第二行直接切换
- **箭头锥形倒刺样式**：新增标准、细长、深倒刺三档，单一闭合路径填充，比例随笔宽等比缩放
- **文字工具增强**：双击任意文字就地编辑、拖拽手柄连续缩放字号、输入框不自动换行（回车断行）、字号所见即所得

### 优化

- 工具栏改为浅色主题（白底 + 深色图标），悬停提示对比度修正
- 粗细调节改用 `ElaSlider`，左右间距与数值文字对齐
- OCR 与二维码合并为「识别」入口，二选一菜单
- 取色信息面板与放大镜改为独立置顶窗口，不再被工具栏遮挡，并互相避让
- 元素识别改为两段式（粗结果立即显示、UIA 精化可作废），拖过界面不再一顿一顿
- 画笔补插中间采样点 + 路径缓存，快速长笔画不再断裂、不再卡顿
- 截图会话在 OCR / 二维码识别成功后自动结束，只保留结果窗口
- 默认标注色改为 `#ED1C24`，所有工具默认笔宽 4px（文字 16px），笔宽档位按从小到大排序

### 修复

- 自动更新需要管理员权限时弹出 UAC，成功后同步 Windows「应用和功能」中的版本号（修复 Program Files 安装无法自动更新）
- Ela 取色器「确定」被误判为取消、点彩虹圆会覆盖调色板色点
- 选中标注后无法拖动选区锚点、鼠标悬停在拖拽点不显示缩放光标
- 选中标注后调整颜色 / 虚线 / 箭头样式不生效
- 文字输入字号与落定后不一致、双击编辑出现重复输入框
- OCR 结果窗口在亮 / 暗主题下文字看不清
